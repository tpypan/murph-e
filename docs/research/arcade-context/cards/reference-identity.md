# Resolve a named game or character

Example evidence: the [Benji Bananas publisher listing](https://play.google.com/store/apps/details?id=com.fingersoft.benjibananas&hl=en) describes monkey/vine swinging and fruit collection. [DC's Batman profile](https://www.dc.com/characters/batman) establishes the character and Gotham setting. Neither text page alone approves a sprite.

Proposed application:

- Separate character, setting, borrowed mechanic and explicit user changes. Resolve aliases without discarding the original transcript.
- Retrieve a concise factual reference and actual images of the intended version. Record source URLs, image hashes, confidence and unresolved ambiguity.
- Extract a visual feature checklist only after inspecting those images. Specify necessary poses and a collision footprint separately.
- Do not import unrelated lore into a short game. Do not replace explicit rooftop jumping with canonical swinging merely because Benji was mentioned.

Checks: correct entity/version; reference image actually supplied to the art stage; required visual features survive at play size; explicit verbs preserved. Ask one clarification only when ambiguity materially changes the game.
