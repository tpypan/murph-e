# Teach through the first encounter

Evidence: [Nintendo's development interview](https://www.nintendo.com/en-gb/Iwata-Asks/Iwata-Asks-New-Super-Mario-Bros-Wii/Volume-2/4-Adjusting-the-Map-in-a-Daily-Cycle/4-Adjusting-the-Map-in-a-Daily-Cycle-233027.html) discusses simplifying early content, anticipating alternate player actions, and repeated adjustment of World 1-1.

Proposed application:

- Show the goal and one actionable obstacle first. Place a reward so using the main action has an obvious payoff.
- Give a recoverable first attempt where the genre allows it. Then repeat with variation before combining hazards.
- Plan what happens if the player misses the reward or presses the wrong direction; do not leave them in an unwinnable waiting state.
- Keep on-screen physical controls visible. Gameplay teaching complements those controls.

Checks: a novice can discover the first action; skipping the first pickup does not softlock; failure gives a legible cause; restart returns to a usable introduction. This is a proposed short cabinet encounter sequence, not a claim that Nintendo used this exact checklist.
