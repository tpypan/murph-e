# Scoring and voluntary risk

Evidence: [Gunroar's instructions](https://www.asahi-net.or.jp/~cs8k-cyu/windows/gr_e.html) link faster advancement to a growing rank multiplier. [The Pac-Man Dossier](https://pacman.holenet.info/) describes escalating rewards for consecutive captures within a temporary opportunity.

Proposed application:

- Name the skill rewarded: precision, efficient collection, chaining, controlled aggression, or survival. Pick one main scoring idea.
- Define events, values, multiplier cap, expiry/reset, and visible feedback. A basic route should score; a riskier route should offer a clear additional reward.
- Key awards to consumed items or unique event IDs, not every overlapping frame. Avoid repeatable no-risk farming.
- Compare scores only under compatible rules/versions; decide explicitly how seeds and adaptive difficulty affect fairness.

Checks: first attainable reward; duplicate collision; combo expiry; maximum multiplier; death/reset; an idle farming attempt. Numeric values are per-game design choices, not universal arcade standards.
