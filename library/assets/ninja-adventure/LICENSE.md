# Ninja Adventure asset provenance

The original artwork in `original/` is by **Pixel-Boy and AAA** and was
published as part of Ninja Adventure under **CC0 1.0 Universal**.

- Creator's asset page: <https://pixel-boy.itch.io/ninja-adventure-asset-pack>
- Canonical CC0 dedication: <https://creativecommons.org/publicdomain/zero/1.0/>
- Full legal terms: <https://creativecommons.org/publicdomain/zero/1.0/legalcode.en>
- Creator's repository: <https://github.com/pixel-boy/NinjaAdventure>
- Pinned source revision: `6ac78232d5aedcc85ce5f27d060ea92366f7c24a`
- Verified on: 2026-09-19

The creator's asset page says:

> They are released under the Creative Commons Zero (CC0) license.

That page links to the official GitHub Godot example from which these images
were downloaded. `source-tree.json` preserves the upstream Git blob hashes;
`manifest.json` and each normalized object also preserve SHA-256 and exact source
paths. No third-party mirror, game ROM or ripped commercial game art was used.

The normalized pixel rows and contact sheet derive from these CC0 images.
Original PNG bytes remain unchanged. Runtime palette mapping is recorded by
`compile.py` and the manifests. Collision rectangles are newly authored technical
metadata, not claims about the creator's original collision design. The imported
content is artwork only: none of the upstream Godot scripts is redistributed.

Attribution is retained for provenance even though CC0 does not require it.
