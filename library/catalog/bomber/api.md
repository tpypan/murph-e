`ARCADE.bomber(config)` returns `{init(api),update(api,dt),draw(api),inspect()}`. Construct inside top-level init and delegate update/draw. Original assets and the complete bomb-arena rules are bundled. Do not regenerate them. `api.players` is authoritative: 1P is solo versus monsters; 2P defaults to versus, or pass `mode:'coop'` for shared clearing. No second start gate.

Options: `levels` integer 1–6 default 2 (solo/co-op); `roundsToWin` 1–5 default 2 (versus); `lives` 1–9 default 3 per player (solo/co-op); `roundSeconds` 20–180 default 100 per arena; `fuseFrames` 60–180 default 100; `blastRange` 1–5 default 2 tiles; `bombCapacity` 1–4 default 1; `moveFrames` 6–12 default 8 per tile; `crateDensity` 0–0.7 default 0.42, deterministic layout; `enemyCount` 0–5 default 3 on level one, increasing by one per level up to 5; `friendlyFire:true` enables teammates' blast damage in co-op (default false; self-blasts always hurt); `sound:false` disables SFX. `mode` only affects 2P and must be `'versus'` or `'coop'`; enemies are disabled in versus. Monsters move faster every two levels, bounded at eight frames per tile. `onEvent(event,api)` receives detached bomb/explode/crate/pickup/enemy-defeated/player-defeated/level-clear/round-end/arena-ready events. Pickup events use `item:'range'|'capacity'|'speed'`. `drawOverlay(api,{mode,level,phase,timeLeft})` draws last. `inspect()` returns diagnostics, not a mutator. No arbitrary roster, map, character art or bomb-type key exists; implement new requested identities/mechanics explicitly instead of inventing config.

Directions move with buffered turns; A plants a bomb; B unused. Bomb owner can leave its tile once, then cannot re-enter. Fuses chain; solid pillars stop blasts, a crate consumes one blast ray, chained bombs launch their own rays. Flame lifetime is 26 frames; upgrades appear after fire and are capped. Bomb capacity is counted per living placed bomb, per owner. Three monster roles are a corridor wanderer, pursuer and threat-aware pursuer; monsters do not plant bombs. Actor contact is lethal outside a 70-frame spawn shield. Death respawns after 65 frames if lives remain. Solo/co-op clears only when all enemies are defeated and someone reaches the visible lower-center exit. Lives/upgrades/scores persist between arenas. Eliminated co-op partners wait; both out or clock expiry calls gameOver. Final team clear calls win().

Versus uses one life per round and preserves wins/scores; upgrades persist between rounds. Last survivor earns 500 and a round win; first to roundsToWin calls win(playerIndex). On timeout, higher score wins the round; tied score or simultaneous knockout ends the match as a draw via gameOver. The runtime has no distinct draw-result overlay. Score: 20 per crate, 200 per monster, 500 per solo/co-op level clear for each teammate. Runtime owns the top score strip. This is an original compact game, not original Bomberman ROM assets or an unrestricted editor.

Example: `let game; function init(api){game=ARCADE.bomber({mode:'coop',levels:3});game.init(api)} function update(api,dt){game.update(api,dt)} function draw(api){game.draw(api)}`
