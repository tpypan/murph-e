# Road and river crossing

Original Frogger-inspired playable foundation with separate traffic, bank and river regions, five visible home bays, two frogs with distinct markings, timers, lives and bounded lane acceleration. Hops are buffered and immediately responsive. Ride velocity is applied on floating supports. Turtles warn before sinking; leaving the field on a log is dangerous. Home reservations prevent duplicate occupancy/score when both cooperative players arrive together.

All artwork is original indexed pixels in `assets.json`: directional resting/hopping frogs, vehicle wheel frames, a textured log, swimming/warning/sunken turtles, and a splash. Frames carry dimensions, center anchors, hit/hurt geometry and clip durations. `build-assets.mjs` reproduces them; `build.mjs` bundles the import-free factory. See `api.md` for exact supported options, actual controls and hooks. `demo.js`/`spec.json` agree: directions only, A/B unused.

Run `node library/catalog/crossing/build.mjs`, then `node library/catalog/crossing/verify.mjs`, then `node library/catalog/crossing/screenshots.mjs`. The behavior verifier checks hops and bounds, traffic/timer deaths and respawn, turtle warning/submerge intervals, log carrying, complete solo five-home routes, cooperative ownership/independent scores and next-level reset, and simultaneous reservations. The read-only route planner chooses actual joystick inputs against future lane positions; it never changes game state. Full routes retain the default moving lanes and sinking turtles and finish without losing a life. Browser replays check those same full inputs in the real repo runtime, rather than teleporting to goals.

`evidence/behavior.json` and `runtime.json` hold the exact results. `scripts/verify-catalog.ts crossing` additionally verifies the actual spec-declared controls in both player counts. Native screenshots are reviewed for distinct safe/hazard lanes, readable home bays, rider placement and turtle warnings. No human difficulty study or physical CRT testing is claimed. This is original compact artwork, not commercial Frogger asset fidelity. Custom character art and arbitrary lane topology are outside the documented configuration.

Version1.1 adds opt-in `homeNotice:'HOME'` and detached `layout()` rectangles. Each player's notice has its own bottom HUD slot, leaving the center TIME readout and frog field clear. Existing event/overlay hooks remain compatible; unrestricted wrapper drawing can still obscure the field. Defaults and scoring are unchanged. The historical generated cartridges in the expanded benchmark are frozen and have not been repaired by this foundation change.

`node library/catalog/crossing/presentation-proof.mjs` replays actual home/line-clear inputs for both this pack and falling-blocks. It checks mechanics/reset, option bounds, unchanged default pixels against saved prior modules, and every customized pixel against the declared safe notice slots or well outlines. Native 1P/2P captures and JSON evidence live under each pack's `verification/presentation/`.
