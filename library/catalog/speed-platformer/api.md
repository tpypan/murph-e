`ARCADE.speedPlatformer(config)` returns `{init(api),update(api),draw(api),inspect()}`. Create inside `init`, delegate once per 60Hz update and draw. `api.players` controls one full view or two independent stacked race views. First racer to finish both acts wins; each has separate rings, lives, collected items, defeated enemies, checkpoints and score. Empty-ring damage costs a life; three lives. A fallen racer respawns at their checkpoint. First to finish both acts wins; if everybody exhausts lives, game over. Runtime START handles terminal replay.

Controls: Left/Right accelerate, brake and reverse. A or Up jumps; hold for height. Down or B while moving rolls. Hold Down+B while stopped to charge a dash; release launches toward current facing. Rings shield one damaging contact, scatter, become recoverable after 24 ticks and expire after 240. Damage grants 120 ticks of invulnerability. Springs launch automatically. Moving downhill increases momentum; rolling retains it. Palm Coast has a physical circular track: enter rightward at >=5.8 pixels/tick, gravity reduces speed going up and returns it going down; insufficient speed falls off; jump detaches along the tangent with an inward jump impulse. The lower bypass is traversable slowly. No forced autoscrolling.

Config: `title` (display only), `actNames` (two display names), `hero` (complete custom set), `objects` (optional map `ring`, `spring`, `enemy`, `checkpoint`, `goal` to custom sets). No other config keys. The default Azure Hare is original artwork, not Sonic.

Sprite set: `{frames:{id:{pixels:string[],palette?:string[],layers?:[{pixels,palette}],anchor:{x,y}}},animations:{clip:{loop:boolean,frames:[{frame:id,duration:positiveInteger,anchor?:{x,y}}]}}`. Canvases <=96×96; each optional plane has exactly the base dimensions, own 1–16 `#RRGGBB` palette and no offsets, at most 8 extra planes. Hex digits are palette indices and dots transparent. Zero is opaque. Base and layers draw in array order, preserve RGB, share feet anchor and mirror, with no scaling or costume recoloring. Clipping at split view boundaries trims source rows without crossing the viewport. Required hero clips: `idle`, `run`, `jump`, `roll`, `skid`, `hurt`, `victory`; optional `walk` at low speed, `spindash` while charging, `spring` while spring-launched, `crouch` while stationary Down, and `ko` on life loss. Objects require `idle`. Frame duration is ticks; anchors can be overridden per animation step. Custom art affects visuals, not the documented 16px-wide/24px-high gameplay body.

`inspect()` is a detached copy of phase, winner, ticks, authored `acts` geometry and `people`. Each player exposes position/velocity, current act, grounded/roll/charge/loop state, checkpoint, rings, lives, animation, enemies, ring placements and statistics. Use for tests and observation, not mutation hooks. This is an original two-act arcade race, not a faithful port of commercial physics/levels. Exact named source art must be supplied explicitly and licensed/reviewed separately.
